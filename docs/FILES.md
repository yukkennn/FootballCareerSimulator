# Описание файлов проекта

Проект состоит из трёх частей, и полезно понимать, какая часть для чего нужна:

- **Игра** (`main.py`, `game/`): то, что запускается и в чём вы играете. Для игры нужны только `data/football.db`, `assets/logos/`, `data/national_strength.csv`, `data/domestic_cups.csv` и `data/real_players.csv`.
- **Сборка базы данных** (`database/`, `tools/`, CSV-файлы в `data/`): нужна, только если вы хотите пересобрать или улучшить базу клубов. Игра их не запускает.
- **Тесты** (`tests/`): проверяют, что всё работает. Игре не нужны.

Во время работы создаются файлы, которых нет в архиве:
- `~/.football_career_sim/saves/*.json`: ваши сохранения (по одному файлу на карьеру; сохранения прошлой версии тоже открываются);
- `~/.football_career_sim/settings.json`: выбранный язык;
- `~/.football_career_sim/error.log`: текст ошибки, если игра упала (особенно полезно для exe: у него нет консоли);
- `.venv/`: виртуальное окружение с PySide6, его создаёт `run.bat` при первом запуске.

## Структура

```
FootballCareerSim/
├─ Football Career Sim.lnk       ярлык: запуск игры (exe)
├─ main.py, run.bat, run.sh      запуск из исходников
├─ build_exe.bat                 сборка .exe
├─ dist/FootballCareerSim/       собранная игра (FootballCareerSim.exe)
├─ requirements.txt, README.md
├─ game/                         код игры (game/ui/ - экраны)
├─ assets/                       эмблемы клубов (logos/) и иконка игры
├─ data/                         football.db и CSV-источники
├─ database/                     сборка и проверка базы (database/importers/ - импорт рейтингов)
├─ tools/                        докачка эмблем, малые лиги УЕФА, иконка
├─ tests/                        проверки
└─ docs/                         документация
```

## Корень проекта

| Файл | За что отвечает |
|---|---|
| `main.py` | Точка входа. Создаёт приложение Qt, читает язык из настроек, применяет оформление, проверяет, что `football.db` на месте (если нет, показывает ошибку), открывает главное окно. |
| `run.bat` | Запуск на Windows двойным щелчком. При первом старте создаёт `.venv`, ставит PySide6 из `requirements.txt`, затем запускает `main.py`. При ошибке пишет подсказку про установку Python и ждёт нажатия клавиши. |
| `run.sh` | То же самое для macOS и Linux. |
| `Football Career Sim.lnk` | Ярлык для запуска игры (exe из `dist`). Создаётся `build_exe.bat`. |
| `dist/FootballCareerSim/` | Собранная игра: `FootballCareerSim.exe` и папка `_internal` (Python, Qt, база, эмблемы). Создаётся `build_exe.bat`; папку можно копировать на другой ПК целиком. |
| `build_exe.bat` | Сборка игры в `dist\FootballCareerSim\FootballCareerSim.exe` через PyInstaller (Windows): ставит PyInstaller, собирает папку с exe (база, эмблемы и Qt внутри, Python не нужен, ~130 МБ), удаляет временную папку `build` и кладёт в корень ярлык «Football Career Sim». Пересобирать после изменений в коде или данных. |
| `requirements.txt` | Список зависимостей игры: одна строка, `PySide6>=6.6`. |
| `README.md` | Короткая инструкция: как запустить, как играть, как устроены награды, ограничения. |
| `game/` | Код игры (см. ниже). |
| `assets/logos/` | Эмблемы клубов. |
| `data/` | Все данные игры: база `football.db` и CSV-файлы, из которых она собирается. |
| `database/` | Сборка, импорт и проверка базы данных. |
| `tools/` | Служебные скрипты: докачка эмблем, составы небольших лиг УЕФА. |
| `tests/` | Проверки. |
| `docs/` | Документация: этот файл и `DATA_SOURCES.md`. |

## `game/`: код игры

| Файл | За что отвечает |
|---|---|
| `__init__.py` | Пустой, делает папку пакетом Python. |
| `paths.py` | Пути: корень проекта (работает и из исходников, и из собранного `.exe`), `data/football.db`, папка эмблем, папка `data`, папка сохранений и файл настроек в домашней папке пользователя. |
| `positions.py` | 13 позиций, названия характеристик (PAC, SHO, PAS, DRI, DEF, PHY; у вратаря DIV, HAN, KIC, REF, SPD, POS), веса характеристик для расчёта общего рейтинга, профили сильных сторон, базовая голевая и ассистентская отдача по позициям, линии (вратарь, защита, полузащита, атака) для символических сборных. Рост и ведущая нога: типичный рост для позиции, как рост сдвигает характеристики (выше - физика и отбор, ниже - скорость и дриблинг; у вратаря прыжок и выходы против скорости) и множители голов и передач (фланговый «на свою ногу» больше передаёт, «перевёрнутый» больше забивает; высокие нападающие и защитники чаще забивают головой). |
| `player.py` | Класс `Player`. Создаёт игрока со случайным скрытым потенциалом (не зависит от стартового рейтинга) и своим возрастом раскрытия: от ранних талантов (16-17 лет) до поздних (23-25). Считает характеристики и общий рейтинг (OVR), рост до 28 лет, влияние игровой практики, результативности и уровня клуба (сильные сезоны до 30 лет поднимают потолок, сезоны на скамейке в 18-25 лет снижают его, травмы скамейкой не считаются), спад с 29-31 года, влияние травм. После хорошего сезона рейтинг не падает (после 31 года падает заметно медленнее). Рейтинг может дорасти до 99. |
| `data.py` | Класс `GameData`: один раз читает `football.db` и CSV в память (страны, лиги с форматом, клубы, турниры, силы сборных, кубки), строит рейтинг стран UEFA и пирамиды лиг, знает, в чьей лиге играют клубы Уэльса, Канады и т.п. Считает звёзды клубов и сборных по порогам EA FC. |
| `world.py` | Класс `World`: «живой мир». Каждый сезон симулирует все 78 лиг (в две половины: `begin_season` / `finish_season`, между ними тренер может сменить тактику), национальные кубки и суперкубки (матчи на вылет со счётом, дополнительным временем и пенальти), Лигу чемпионов, Лигу Европы, Лигу конференций, Суперкубок УЕФА, Кубок Либертадорес, Копа Судамерикана, Лигу чемпионов АФК. Для сборных: отборочные группы и стыковые матчи, межконтинентальный плей-офф ЧМ, финальные турниры (ЧМ, ЧЕ, Копа Америка, Кубок Африки, Кубок Азии, Золотой кубок, Кубок ОФК), Лига наций УЕФА в годы без отбора (дивизионы A-D хранятся между розыгрышами: победители групп B-D поднимаются, последние в группах A-C опускаются; у дивизиона A финал четырёх). Для каждого клуба и сборной сохраняет итог: место, стадию вылета, соперника и счёт. Потом проводит повышения и понижения (Англия, Испания, Германия с 3. Лигой, Италия, Франция) и немного меняет силу клубов и сборных. |
| `stats.py` | Модель индивидуальной статистики (одна для вашего игрока и для звёзд мира): ожидаемые голы и передачи за матч в зависимости от рейтинга игрока, силы его команды и соперников; сухие матчи; средняя оценка за сезон (6.0-8.5); очки Золотого мяча (статистика с поправкой на уровень лиги + трофеи клуба и сборной + класс игрока). |
| `stars.py` | Звёзды мира: не меньше 90 соперников в борьбе за награды. Реальные игроки читаются из `data/real_players.csv`: 109 звёзд 2026 года (от Ямаля и Мбаппе до Месси и Роналду на последнем сезоне в элите), 65 перспективных игроков 16-22 лет (Карл, Нванери, Дауман, Эндрик, Йоро и др.) и 400 известных игроков клубов (`pool["others"]`: стареют, переходят, первыми занимают освободившиеся места среди звёзд; когда реальные уходят, список пополняется сгенерированными до 300). Функции `players_at` (известные игроки клуба), `find`, `add_other` - для трансферов тренера. У молодых звёзд и перспективных игроков потенциал в каждой карьере свой: кто-то раскрывается, кто-то нет. Перспективный игрок попадает в звёзды мира (и в голосование за Золотой мяч) с OVR 80, не доросший к 24 годам уходит из списка. Звёзды стареют, переходят в другие клубы и уходят из элиты, свободные места занимают молодые таланты со сгенерированными по стране именами. |
| `career.py` | Класс `Career`: сама карьера. Выбор академий (90% своя страна, 10% другая; если в стране нет лиги, академии из нескольких стран: запасная страна из `academy_fallback.csv`, соседи по конфедерации и иногда сильная лига мира; подпись «из вашей страны» / «зарубежная» / «в вашей стране нет лиги»), сезон в академии (молодёжная лига U-18, иногда вызов в основу на кубок или дебют в лиге), взрослый сезон со статистикой по каждому турниру отдельно, сборная (итоги сборной записываются всегда, статистика игрока при вызове), награды (Золотой мяч и символическая сборная мира против звёзд мира, игрок сезона, символическая сборная лиги, Золотая бутса, лучший молодой игрок), травмы, рост, предложения клубов (в новых карьерах после каждого сезона), аренда, завершение карьеры (само в 40 лет или по кнопке), итоговый отчёт, сохранение и загрузка (с переводом старых сохранений). |
| `coach.py` | Тренерская карьера (`CoachCareer`, состояние в `career.coach`). Старт из игровой карьеры: тренерский навык и репутация считаются по пику рейтинга, трофеям, наградам и матчам за сборную. Предложения клубов по репутации (своя страна и бывшие клубы чаще), у части - «проект на перспективу (перестройка)». Задача клуба - ожидаемое место по силе среди соперников по лиге (в выровненной лиге ближе к середине). Сезон: навык тренера даёт команде небольшую прибавку к силе; раздражение руководства (0-100) растёт за место ниже задачи (сильнее при большом провале) и вылет, падает за трофеи, кубки и еврокубки; давление в топ-клубе x1.8, в маленьком x0.6, при перестройке вдвое меньше; каждый сезон остаётся 60% прошлого раздражения. На 100 - увольнение и новые предложения (похуже), по концу контракта - продление или новый клуб. Награды «Тренер сезона в лиге» и «Лучший тренер мира» (против реальных тренеров, `coaches.py`). Перед сезоном и в середине - ротация; после каждой половины состав устаёт, получает травмы и дисквалификации (`squad.play_half`), в конце сезона - недовольные без игры (`squad.end_of_season`). Конец - по кнопке или в 70 лет. Тактика (баланс / атака / оборона / прессинг) на каждую половину сезона: атака выгодна сильной команде, оборона - аутсайдеру, прессинг - только сильному тренеру и выматывает, если играть им весь сезон. Сезон идёт в две половины: после первой руководство оценивает таблицу и может уволить посреди сезона. Отношения с клубами: уволивший клуб долго не позовёт, клуб, где выиграл титул, зовёт охотнее; в клубе, где помнят плохо, раздражение с первого дня не ноль. Рекорды тренера: самая долгая работа, легенда клуба (10+ сезонов), серия без увольнений, трофеи по клубам, лучший сезон, главный прорыв, самая короткая работа. |
| `squad.py` | Состав клуба тренера: 23-30 игроков по позициям (известные игроки клуба + сгенерированные по шаблону, подогнанные так, чтобы сила основы совпала с рейтингом клуба). 17 схем с вариантами стиля (например, 4-3-3 баланс / атакующая с CAM / оборонительная с двумя CDM, 4-4-2 баланс / оборонительная / ромб, 4-2-3-1 через фланги, 4-3-1-2, 4-5-1, 3-5-2, 3-4-1-2, 3-4-3, 5-3-2, 5-4-1); атакующие - больше голов в обе стороны. Основа подбирается по схеме с доводкой обменами; игрок не на своей позиции теряет 2-8 (соседняя), 12 (та же линия), 20 (другая линия) OVR. Сила клуба тренера в мире = средний OVR основы. Воспитанники академии поднимаются, если состав меньше 22 или не хватает позиции; лимит заявки 30. Основу можно выбрать вручную (`set_lineup`, своя для каждой схемы; ушедших заменяют лучшие из оставшихся) или доверить автоматике (`current_xi`). Потенциал в таблицах: вилка у растущих (ширина - по скаутам), «на пике», «угасание» с 31 года (`pot_state`). Форма (усталость основы, отдых запасных, +10 в зимнюю паузу, 100 летом; усталость снижает OVR в матчах), травмы и дисквалификации (пропуск 1-3 половин сезона), ротация (только основа / умеренная / сильная: запасные получают 15-30% минут, часть матчей играет второй состав). Роли: основа, ротация (не больше чем на 5 OVR слабее среднего игрока основы - сама получает ~30% минут) и резерв. Трансфер просит только тот, кто сильнее среднего игрока основы, а почти не играет (играет на 2 слабее). Академия каждое лето выпускает 1-2 игроков разных позиций (чаще - позиций своей схемы) и закрывает позиции, на которые в схеме не хватает игроков. Минуты сезона нужны молодым: без игры растут втрое медленнее (`stars._age_one`). |
| `transfers.py` | Трансферы тренера. Бюджет клуба в год (млн €) - по финансовому масштабу клуба (исходная сила из базы, 70%) и уровню лиги, плюс призовые за сезон (титул, кубки, еврокубки) и деньги от продаж; неистраченное остаётся. Трансферное окно летом (12-20 кандидатов, больше с хорошими скаутами) и зимой (6-10): известные игроки мира (не больше двух дорогих «мечт», остальные по карману) и сгенерированные кандидаты под бюджет, чаще на слабые позиции основы; у молодых - вилка возможного рейтинга. Молодёжь: талант 17 лет в состав или вложение в академию (3 сезона воспитанники сильнее). Продать можно любого игрока состава; иногда большой клуб предлагает за лучшего игрока на 25-60% больше (клуб и сумма видны). Эффект сделки = изменение силы основы в выбранной схеме. Купленный реальный игрок переходит в ваш клуб по-настоящему. Сильный игрок (на 4+ сильнее команды) часто отказывается от клуба без еврокубков. Аренда: летом 3 игрока клубов посильнее на сезон за 10% стоимости; своего игрока можно отдать в аренду (клуб его уровня, растёт от игры), другие клубы сами просят молодых и запасных; летом аренды заканчиваются. Скауты (до 3, 1-5 звёзд по рейтингу 40-95, зарплата каждое лето): сужают вилку потенциала (10 -> 2), расширяют рынок и находят «жемчужины» (◆ - молодые с потенциалом выше цены). |
| `coaches.py` | Тренеры мира для награды «Лучший тренер мира»: реальные тренеры топ-клубов (назначения сезона 2025/26), стареют вместе с миром, меняют клубы, уходят на пенсию в 70; свободные места в 36 сильнейших клубах занимают сгенерированные. Очки сезона = успехи клуба (как в Золотом мяче) + перевыполнение задачи + навык. |
| `saves.py` | Запись и чтение сохранений в JSON, список сохранений, удаление. Запись идёт через временный файл, чтобы не испортить сохранение при сбое. |
| `i18n.py` | Все тексты интерфейса на русском и английском (248 ключей), функция `tr()`, запоминание выбранного языка. |
| `text.py` | Помощники для текстов: деньги, названия трофеев, звёзды, склонение «матч/матча/матчей», короткие названия трофеев, счёт матча («2:2 (1:0, 1:2) д.в., пен. 4:3»), итог клуба в турнире, итог сборной в отборе, Лиге наций и на турнире. |

### `game/ui/`: интерфейс

| Файл | За что отвечает |
|---|---|
| `__init__.py` | Пустой, делает папку пакетом. |

## `database/`: сборка и проверка базы

Нужно, только если вы хотите пересобрать или улучшить базу клубов. Игра эти скрипты не запускает. Все команды - из корня проекта.

| Файл | За что отвечает |
|---|---|
| `build_db.py` | Собирает `football.db` с нуля: берёт файлы из `data/`, эмблемы и составы высших лиг из репозитория football-logos и названия клубов из репозитория openfootball/clubs. Приводит эмблемы к высоте 96 пикселей, сопоставляет клубы с псевдонимами, добавляет нижние лиги и Казахстан, в конце запускает импорт FC 27 (`database/importers/import_fc27.py`). Запуск: `python build_db.py --logos-repo ПАПКА --openfootball ПАПКА`. |
| `schema.sql` | Описание таблиц базы: `meta`, `confederations`, `countries`, `leagues` (с колонкой `rounds`: сколько раз встречаются две команды), `clubs`, `club_aliases`, `club_signals`, `club_top_flight_history`, `competitions`, `career_log` и представление `v_country_coverage`. Таблица `career_log` сейчас **не используется**: сохранения игры идут в JSON. |
| `recompute_stars.py` | Считает силу клуба (0-100) и звёзды (0,5-5) из сигналов в `club_signals`. Сила = 2,5 · (OVR команды − 48); у клубов слабее OVR 48 сила отрицательная (нижняя граница OVR 35, сила −32,5), чтобы полупрофессиональные лиги отличались друг от друга. Приоритет: рейтинг FC 27, затем Elo, затем ручная оценка, затем старые слабые сигналы. Пороги звёзд как в EA FC: 5★ от OVR 82. Вызывается из `build_db.py` и импортёров, можно запускать отдельно. |
| `validate_db.py` | Проверки целостности базы: 211 стран, состав конфедераций, размеры лиг (не меньше 8 клубов), внешние ключи, эмблемы, клубы в чужих лигах (Уэльс, Андорра, Канада, Новая Зеландия, Лихтенштейн), 4 фарм-клуба, у каждого клуба есть рейтинг, у каждой лиги задан формат, запасные академии. Печатает итоги и покрытие стран клубами. |
| `importers/__init__.py` | Пустой, делает папку пакетом. |
| `importers/common.py` | Общие функции: нормализация названий клубов, поиск клуба по названию и псевдонимам (с неточным совпадением), запись сигналов, пересчёт звёзд. |
| `database/importers/import_fc27.py` | **Импорт базы EA FC 27**: сборные в клубы не попадают, рейтинги известных клубов по `fc27_club_map.csv`, новые лиги и клубы из `world_leagues.csv` / `world_clubs.csv`, ручные оценки, сила лиг, формат лиг, запасные академии, пересчёт звёзд. Женские команды пропускает. Можно запускать повторно: `python database/importers/import_fc27.py data/football.db`. |
| `importers/import_elo_csv.py` | Загружает Elo клубов из вашего CSV (например, с Kaggle) в базу и пересчитывает звёзды. Колонки определяются автоматически. Проверен только на синтетическом файле. |
| `importers/import_ea_fc.py` | Считает рейтинг команд (среднее 14 лучших игроков) из датасета игроков EA FC и записывает в базу. Проверен только на синтетическом файле. |

## `assets/logos/`

1127 файлов PNG высотой 96 пикселей (14,5 МБ): 433 из репозитория football-logos, остальные докачаны `tools/fetch_logos.py`. Имя файла совпадает с идентификатором клуба в базе (колонка `clubs.club_id`): например, `eng-arsenal-fc.png` или `ger-bayern-munich.png`. Первые три буквы названия показывают страну клуба. Путь к каждой эмблеме записан в колонке `clubs.logo_path`. Без эмблемы 7 клубов (4 фарм-клуба, San Marino Academy U22, Juvenes/Dogana, United Tigers SC), для них игра рисует круг с инициалами.
