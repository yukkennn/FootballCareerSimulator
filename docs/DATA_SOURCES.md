# База данных симулятора: источники, статус, что делать дальше

Версия 4 от 15.10.2026: высшие лиги всех ассоциаций УЕФА (добавлены 28 лиг от Кипра до Сан-Марино), коэффициенты УЕФА 2027 года.
Версия 3 от 12.10.2026: добавлена база команд EA FC 27 (`data/fc27_teams.csv`) и новые лиги.
Сезон данных: 2026/27 (лиги с календарным годом, например Казахстан, MLS, Южная Америка, Исландия, Ирландия: сезон 2026 или 2027 = 2026/27 в игре).

### Небольшие лиги УЕФА (версия 4)
28 высших лиг: Кипр, Венгрия, Азербайджан, Словения, Словакия, Исландия, Ирландия, Армения, Косово, Босния и Герцеговина, Латвия, Финляндия,
Молдова, Фареры, Албания, Северная Македония, Беларусь, Литва, Андорра, Мальта, Гибралтар, Эстония, Северная Ирландия, Грузия, Люксембург,
Черногория, Уэльс, Сан-Марино. Данные и пояснения в `tools/uefa_small_leagues.py`.
- **Составы**: страницы сезонов 2026/27 (у лиг «весна-осень» сезон 2026) в английской Википедии, октябрь 2026. Для Андорры, Черногории и Сан-Марино
  таких страниц нет: взят состав 2025/26 с известными изменениями. Transfermarkt был недоступен для загрузки.
- **OVR**: средний уровень лиги по коэффициенту УЕФА 2027 года, сверенный с лигами, которые уже были в базе (при том же коэффициенте средний OVR
  близок: коэфф. ~25 → ср. ~62-64, коэфф. ~14 → ~59). Ниже коэффициента ~10 лиги полупрофессиональные, шкала круче: Андорра 44, Гибралтар 43,
  Уэльс 45, Сан-Марино 40 (минимум 36). Чтобы такие клубы различались, сила клуба может быть отрицательной (нижняя граница OVR 35, раньше было 48).
- **Опоры из FC 27**: АПОЭЛ 70, Омония 70, Ференцварош 70, Карабах 69, ХИК 65 (раньше пропускались, потому что их лиг не было).
- **Особые случаи**: Дерри Сити (Северная Ирландия) играет в лиге Ирландии; San Marino Academy U22 помечена как фарм-клуб.
  4 валлийских клуба (Кардифф, Суонси, Ньюпорт, Рексем) по-прежнему в английской системе, а в Cymru Premier 16 других валлийских клубов.

### Правила, которые нужно знать
- **Клуб страны ≠ лига страны.** Валлийские клубы играют в Англии (`country_code = WAL`), ФК Андорра в Испании, Торонто, Ванкувер и Монреаль в MLS (`CAN`),
  Окленд и Веллингтон в A-League (`NZL`), Вадуц в Швейцарии (`LIE`). Игрок этих стран увидит их как «свои» клубы, остальные академии берутся из лиги-хозяина.
- **Фарм-клубы** (Celta de Vigo B, Real Sociedad B, VfB Stuttgart II, TSG Hoffenheim II) помечены `is_reserve = 1`: в предложения трансфера не попадают,
  в высший дивизион не поднимаются (в Германии и во второй).
- **Запасные академии** (`data/academy_fallback.csv`): для 138 стран без клубов. Принцип: язык и история (Мексика → Испания, Алжир → Франция),
  для арабских стран Азии теперь Саудовская Аравия, для Океании Австралия. Файл можно править.

## 2. База EA FC 27 (`data/fc27_teams.csv`)

Файл: 707 строк, колонки `team_id, team_name, ovr, att, mid, def, budget`. Женских команд в нём нет (импортёр всё равно их отсеивает).

| Что | Сколько | Куда пошло |
|---|---|---|
| Сборные (строки с названием страны) | 51 | **не клубы**: рейтинг перенесён в `data/national_strength.csv` (колонка `fc_ovr`), по нему считаются сила сборной и звёзды при выборе страны |
| «MLS All Stars» | 1 | пропущена (не клуб и не сборная) |
| Клубы, которые уже были в базе | 444 | сигнал `ea_team_ovr`; явный список соответствий: `data/fc27_club_map.csv` |
| Новые клубы | 205 | `data/world_clubs.csv` (+ 45 клубов, добавленных вручную для полноты лиг) |
| Клубы без лиги в базе | 2 | пропущены: Аль-Айн, Бурирам (Ференцварош, АПОЭЛ, Омония, Карабах, ХИК с версии 4 в своих лигах) |

FC 27 называет некоторые клубы без лицензии: Lombardia FC = Интер, Milano FC = Милан, Bergamo Calcio = Аталанта. В игре остаются настоящие названия.

### Клубы, которых нет в FC 27
Им проставлен OVR вручную (`data/club_ovr_estimates.csv`, 118 клубов: Россия, Сербия, Израиль, Болгария, Казахстан, часть Чехии, Греции,
Хорватии, Украины), ориентируясь на клубы FC 27 той же лиги (их лучшие клубы в FC 27 есть) и на уровень лиг в мировых рейтингах.
Пример: Кайрат и Астана 64 (рядом с ХИК 65 и Вадуцем 62 из FC 27), Зенит 74, Црвена звезда 72.
45 клубов, добавленных для полноты неполных лиг (Интернасьонал, Коло-Коло, Альянса Лима и др.), тоже с ручной оценкой (`est_ovr` в `world_clubs.csv`).

### Сила лиг вне Европы
`data/world_league_strength.csv`: по мировым рейтингам лиг (Бразилия ≈ между Португалией и Францией, Аргентина ≈ Чехия/Греция, MLS ≈ Норвегия,
Саудовская Аравия ≈ Швейцария, Индия ≈ Люксембург). Влияет на очки за статистику в наградах и на цену переходов.

### Сборные
51 сборная с рейтингом FC 27. Для остальных прежняя оценка пересчитана на шкалу FC 27 (линейная связь по 51 сборной, для слабых сборных круче вниз),
Казахстан (65) и Россия (72) оценены вручную. Звёзды сборной: те же пороги, что у клубов, минимум 1★.

## 3. Звёзды клубов (0.5-5)

Сила клуба `star_score` (0..100) = 2.5 · (OVR команды − 48), то есть OVR команды в игре = 48 + 0.4 · сила (как в FC 27).
Источник OVR по приоритету: рейтинг FC 27 → Elo (если загрузите) → ручная оценка → старые слабые сигналы.
Пороги как в EA FC (по OVR команды): **5★ от 82**, 4.5★ от 79, 4★ от 76, 3.5★ от 73, 3★ от 70, 2.5★ от 67, 2★ от 64, 1.5★ от 61, 1★ от 57, ниже 0.5★.
5★ у 10 клубов: ПСЖ, Реал, Барселона, Арсенал (85), Бавария, Ман Сити (84), Ливерпуль, Атлетико (83), Интер, Манчестер Юнайтед (82).

## 5. Эмблемы

- **1127 из 1134 клубов имеют эмблему.** 433 взяты из репозитория football-logos, 694 докачаны `tools/fetch_logos.py` (16.10.2026):
  615 из TheSportsDB, 17 из Викиданных (Викисклад), 62 из карточек статей Википедии (у 19 клубов статья задана вручную,
  у Иртыша и Каспия - русская Википедия, у Ауды - латышская). Что откуда взято - `data/logo_sources.csv`.
- Все 694 докачанные эмблемы просмотрены глазами на листах-превью. Отсеяны молодёжные, резервные и женские команды (Kapaz II,
  Partizani B и т.п.), другой клуб с похожим названием (Central Córdoba de Rosario) и текстовый логотип вместо эмблемы (Миннесота).
- Без эмблемы 7 клубов: 4 фарм-клуба (у них намеренно нет чужих эмблем), San Marino Academy U22, Juvenes/Dogana и United Tigers SC
  (эмблем нет ни в одном источнике). Вместо эмблемы игра рисует круг с инициалами.
- Докачать ещё раз (например, после пересборки базы): `pip install pillow`, затем `python tools/fetch_logos.py data/football.db`.

## 6. Что сделать на вашем ПК (там есть доступ в интернет)

```bash
git clone --depth 1 https://github.com/luukhopman/football-logos.git
git clone --depth 1 https://github.com/openfootball/clubs.git
pip install babel pillow
python database/build_db.py --logos-repo football-logos --openfootball clubs     # пересборка с нуля (в конце сам запускает импорт FC 27)
python database/importers/import_fc27.py data/football.db                             # или только импорт FC 27 в готовую базу (можно повторять)
python database/validate_db.py                                                   # проверки целостности

# Новая версия файла команд EA FC: положите её в data/fc27_teams.csv и запустите import_fc27.py.
# Если появились клубы, которых нет в fc27_club_map.csv / world_clubs.csv, импортёр перечислит их в отчёте.

python database/importers/import_elo_csv.py data/football.db Elo.csv                  # Elo (важнее ручной оценки, но не рейтинга FC 27)
python tools/fetch_logos.py data/football.db                                 # недостающие эмблемы
```

Тесты: `python tests/test_importers.py`, `python tests/test_fetch_logos.py`.

## 7. Известные ограничения

1. **Состав лиг фиксирован на сезон 2026/27.** Дальше лиги живут в симуляции (повышения и вылеты в Англии, Испании, Германии, Италии, Франции).
2. **Неполные лиги Южной Америки** в игре короче настоящих (8-12 клубов), число туров подобрано близким к реальному.
3. **MLS и Аргентина** играют по одному кругу (29 туров), плей-офф MLS не моделируется: чемпион = первое место.
4. **Нет лиг ОАЭ, Таиланда, Мексики, Японии и Африки**, поэтому нет Кубка чемпионов КОНКАКАФ и клубных турниров КАФ.
5. **Квалификация еврокубков не моделируется**: места в ЛЧ, ЛЕ и ЛК (по 36 клубов) раздаются по рейтингу УЕФА, и чемпионы самых слабых лиг
   попадают туда, только если остались свободные места (в жизни они обычно вылетают в квалификации).
6. **OVR клубов 28 небольших лиг - ручная оценка**, а не данные EA (кроме пяти опорных клубов из FC 27).
